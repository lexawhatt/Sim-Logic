# Ferris artwork

`ferris.png` is the original user-supplied transparent 460x307 PNG, embedded
unchanged (40,445 bytes). No generated pixel table or runtime file is required.

Ferris was created by Karen Rustad Tölva. The artwork has a
[CC0 public-domain dedication](https://rustacean.net/), separate from the
library's MIT/Apache-2.0 code license. The website favicon has a different
license; it is not used here.
